# 归档页

主题内置时间线式文章归档页（`/archives/`），按**年份分组**展示全部文章，适合读者按时间维度浏览你的全部内容。

![归档页：按年份分组的时间线式文章列表](/img/archive.png)

## 配置

归档页由 Hexo 原生 `archive` 生成器提供（无需额外插件），主题负责渲染。是否在导航栏显示入口由 `nav.archive` 控制：

```yml
nav:
  archive: true # 导航栏显示「归档」入口，指向 /archives/
```

不开启导航入口时，页面依然存在，可通过链接（如页脚）手动引用。

## 页面结构

- 顶部为「归档」标题与文章总数
- 正文按年份分组，年份标题右侧以分隔线延伸
- 每篇文章一行：`MM-DD 日期 + 文章标题`，左侧时间线（竖线 + 圆点）
- 鼠标悬停时时间线与圆点高亮为主题色
- 文章较多时自动分页

## 说明

- 归档页地址由 Hexo 站点配置 `archive_dir` 决定，默认 `archives`
- 与「子页」互补：子页按**领域**聚合，归档页按**时间**聚合
- 深浅色模式均适配
