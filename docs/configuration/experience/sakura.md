# 樱花飘落

全站装饰动画：花瓣自页面上方缓缓飘落，飘过正文上方，为站点增添一分氛围感。

![首页樱花飘落效果](/img/sakura.png)

## 配置

```yml
sakura:
  enable: true
  density: 16 # 同屏花瓣数量，移动端自动减半
```

## 配置项说明

| 字段 | 说明 |
| --- | --- |
| `sakura.enable` | 是否开启樱花飘落 |
| `sakura.density` | 同屏花瓣数量，默认 16；移动端（< 768px）自动减半 |

## 性能与无障碍

装饰动画以「不干扰」为第一原则：

- **纯 CSS 硬件加速**：动画仅使用 `transform` / `opacity`，不触发重排重绘，滚动与输入不受影响
- **不拦截交互**：花瓣层 `pointer-events: none`，链接、按钮、文本选择完全正常
- **无障碍降级**：系统开启 `prefers-reduced-motion`（减弱动态效果）的访客自动停用动画
- **移动端减量**：小屏幕花瓣数量自动减半，兼顾观感与功耗

## 说明

- 樱花层位于正文上方、导航栏下方，全站所有页面生效
- 每片花瓣的大小、下落时长、摆动幅度、旋转与透明度均随机生成，观感自然
- 深浅色模式下均可见
