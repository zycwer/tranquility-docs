# Post Reward

Configure post reward via the `reward` option, including avatar, QR code, and text.

```yml
reward:
  enable: true
  face: /assets/author-face.jpg # avatar image
  paycode: /assets/pay-code.jpg # QR code image
  text: "Buy the author a cappuccino"
  btnText: Like the author
```
