# Code Highlighting

Code highlighting depends on the `highlight` config in your blog's **root** `_config.yml`. Configure as follows:

```yml
highlight:
  enable: true
  line_number: true
  auto_detect: false
  tab_replace: ""
  wrap: true
  hljs: true
prismjs:
  enable: false
  preprocess: true
  line_number: true
  tab_replace: ""
```
